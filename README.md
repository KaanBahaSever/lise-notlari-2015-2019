# Lise Notları 2015–2019

Lisede, bilişim derslerinde yaptığım C# ve web ödevleri. Projeler konuya göre klasörlendi.
Çoğu Visual Studio 2012/2017 ile yazılmış .NET Framework projeleri.

| Klasör | Konu |
|---|---|
| `01-temel-islemler` | Değişkenler, atama, aritmetik ve mod işlemleri, konsola yazma |
| `02-kosullar` | `if` / `else if` örnekleri: not ortalaması, hesap makinesi, indirim |
| `03-donguler` | `for` ve `break`, tek ve çift sayıların toplamı |
| `04-diziler` | Tek ve iki boyutlu diziler, sıralama, en büyük ve en küçük değer |
| `05-metotlar` | Değer döndüren metotlar, metoda dizi gönderme |
| `06-windows-forms` | Form kontrolleri: renkler, görünürlük |
| `07-siniflar` | Sınıf, `get` / `set` ve doğrulama |
| `08-dosya-islemleri` | Klasör ve dosya oluşturma, `StreamWriter` |
| `09-veritabani` | Access (OleDb) ve SQL Server ile kayıt ekleme ve listeleme |
| `10-html-javascript` | Fare olayları, iki sayıyı toplama |

## Notlar

- Yalnızca kaynak kod var. `bin`, `obj` ve `.vs` klasörleri ile derlenmiş dosyalar repoya eklenmedi.
- `09-veritabani` klasöründeki Access projeleri `dosya.accdb`, SQL Server projesi de `Ticaret` / `CBaglanti` veritabanlarını bekliyor. Bu veritabanları repoda yok.
